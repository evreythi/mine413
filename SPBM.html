Looking for SPBM on this computer…

SPBM is not running yet. A web page cannot start a program by itself (browsers do not allow it), so start it once with the launcher in this folder:

  1. Windows: double-click Start SPBM (Windows).bat
  2. Mac: double-click Start SPBM (Mac).command (the first time, right-click it and choose Open)
  3. Linux: run ./start_spbm.sh

The first start sets everything up (a few minutes, needs Python 3.10 or later). After that the page opens by itself in a few seconds, and SPBM stops on its own about 15 minutes after you close the page. This page will also open SPBM automatically as soon as it is running.
